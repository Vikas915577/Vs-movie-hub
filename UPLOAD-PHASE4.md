# Phase 4 upload instructions (Android-friendly)

1. Download and extract `vs-movie-hub-phase4-seo.zip`.
2. Open the public repository `Vikas915577/Vs-movie-hub`.
3. Upload the extracted files to the repository root on `main`. Choose **Replace** for same-name files.
4. Keep `movies.js`, `phase3.js`, `phase3.css`, `movie-detail.js` and `favicon.svg` from the repository. This package does not overwrite those core data/logic files.
5. Replace `index.html`, `rankings.html`, `compare.html`, `release-calendar.html`, `about.html`, `contact.html`, `methodology.html`, `privacy.html`, `robots.txt`, and `sitemap.xml`.
6. Add the 20 `movie-*.html` pages, `og-image.png`, `404.html`, `phase4-seo.js`, `SEO-SETUP.md`, and `SEO-QA-REPORT.json`.
7. Commit to `main`, wait for GitHub Pages deployment, then check the homepage, a movie report, rankings, compare and release calendar on mobile.

**Do not upload `UPLOAD-PHASE4.md` into the public website unless you want setup instructions visible there.**

After deployment, complete Google Search Console verification yourself using the exact HTML verification file downloaded from your account. Then submit `sitemap.xml`.
